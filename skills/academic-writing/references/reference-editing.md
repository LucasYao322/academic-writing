# 参考文献整理

区分格式校正、元数据核实和引文是否支持论点，三者不能相互替代。

## 输入与流程

1. 识别用户指定的期刊格式、APA 版本或样例模板。规则有实质冲突时指出冲突，不混用多套样式。
2. 保留原有作者、年份、题名、期刊、卷期、页码及 DOI。格式化不得改写文献题名含义。
3. 调整作者书写、大小写、排序、标点和链接形式。仅在已知官方全称时展开期刊缩写。
4. 缺失元数据单独列出待核实项。禁止凭题名推断 DOI、卷期、页码或作者，不生成示例链接冒充真实来源。
5. 用户要求核查且具备工具时，访问出版商、DOI 注册元数据或可信书目来源核对。查不到或来源冲突时保留未确认状态。
6. 需要检查正文时核对引用与文末条目是否双向对应。核查文献存在不等于核查全文支持某项论断。

## 输出与格式

默认交付修正列表，存在缺项时附简短问题清单，不把待核实文字混入可投稿条目的字段。
参考文献使用指定规范的标点、DOI、斜体及其他必要格式，不执行正文仅逗号句号的规则。
用户要可复制代码块时可以提供，但说明代码块只显示斜体标记，不渲染真实斜体。不要同时声称格式效果已完整呈现。
没有实施外部核实时，只声称完成格式整理。
